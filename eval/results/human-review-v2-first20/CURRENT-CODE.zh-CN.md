## 在同一上游输出上重放机制

独立运行的方案之间会有模型输出波动。为了隔离各环节的作用，用同一次运行保存的专家输出重放确定性逻辑：

- **语境节点**：改变 2 条，纠正 1 条（`d0dc544b`），改错 1 条（`1ff26f79`）。
- **裁决 agent + 置信门槛**：裁决触发 2 次，均提交有效结果，最终都是交人工，与聚合器原本的结论一致，改变 0 条。

所以 specialist_panel 和 policy_agent 之间 13 对 11 的差距，来自两次独立调用的波动，不是裁决造成的。
这批数据里，裁决 agent 没有纠正也没有改错任何动作。
