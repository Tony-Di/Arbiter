# 本地改进记录：2026-09-22

本轮完善本地版本，没有部署网站。目标是让规则、裁决和人工审核能够被验证和解释。

## 已实现

- **统一政策**：分类提示、语境提示、裁决工具和标注校验共用 `moderation_policy.py`。
  普通定向辱骂为 severity 2，进入人工复核；明确严重伤害才可自动删除。
- **引用用途与证据**：区分转述、谴责、赞同和直接攻击。仅有 quotation/sarcasm 标签
  不再自动减分；减分必须指明类别、用途、理由和原文片段。原文匹配是可验证约束，
  不能保证模型的语义判断正确。
- **收窄 agent 职责**：明确的普通辱骂直接进入人工队列。裁决 agent 处理有风险的语境歧义；
  提交结果必须有合法动作/严重程度、政策类别、原文证据和有效置信度。错误输出进入人工复核。
- **人工决定可靠保存**：先保存人工选择，再恢复 LangGraph，最后在同一数据库事务内保存
  裁决、完成状态和向量化任务。相同请求可重试，冲突决定返回 409；恢复后已完成的 checkpoint
  可以继续落库。原始判断、政策/提示版本和运行模型配置可追溯。
- **判例异步入库**：embedding 不再阻塞人工决定保存。后台每 5 秒检查队列，失败后退避重试，
  每个审核 case 只入库一条判例。向量服务恢复前，人工裁决已经保存，但该判例暂不可检索。
- **本地兼容与界面**：启动时添加数据库字段并保留旧数据；关闭时释放 checkpoint 连接。
  队列支持重试已记录的决定，展示原因和证据；真实案件断网不再显示为已处理。

## 本地使用

```powershell
# 项目根目录；Python 3.13+
.venv\Scripts\python -m pytest -q
.venv\Scripts\python -m uvicorn arbiter.api.main:app --reload

# 另一个终端
cd web
npm run dev
```

密钥保存在被 Git 忽略的 `.env`。默认模型使用现有路由表和 registry；需要可用的 GPT、
DeepSeek 配置。`.env.example` 只保留占位符。前端打开 `http://localhost:5173`。
选择明确辱骂示例可看到直接进入人工队列；选择引用/讽刺示例可查看用途和证据。
“存在歧义”由模型判断，并非每个含引号的输入都会调用裁决 agent。

审核时使用 Allow 或 Remove；Confirm 仅适用于已有明确建议的案件。请求中断后刷新队列，
重试原决定；正在保存的请求可能短暂返回 409，进程异常退出后的租约最长等待 120 秒。
再次提交相同决定返回已保存结果，不会产生重复裁决或重复判例。

API 运行时自动处理向量任务，也可以在项目根目录单次执行：

```powershell
.venv\Scripts\python scripts/process_precedents.py
```

该命令只处理已到重试时间的任务，不跳过退避；API 密钥缺失时任务会保留并重试。
备份本地数据时停止后端后一起复制 `arbiter.db` 和 `checkpoints.db`；不要删除旧库来升级。
如果设置了 `DATABASE_URL` 或 `CHECKPOINT_DB`，备份对应路径。
